## 📖 Overview

Agriculture in India is heavily influenced by environmental conditions, market fluctuations, and resource availability. Farmers often struggle with questions like:

- Which crop should I grow?
- Will I make a profit?
- How much fertilizer should I use?
- When should I irrigate?
- Which mandi will give the best price?

**AgriNova** answers these questions using Artificial Intelligence, IoT, and data-driven recommendations.

Instead of being just an irrigation system, AgriNova acts as an **AI Agriculture Copilot** that assists farmers throughout the complete farming lifecycle.

# ✨ Features

## 🌾 Smart Crop Recommendation

Recommends the top 4–5 crops based on:

- Soil Type
- Soil Moisture
- Soil pH
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Weather Conditions
- Rainfall
- Groundwater Availability
- Market Prices
- MSP (Minimum Support Price)

- Water-saving suggestions

## 🧪 Fertilizer Recommendation

Provides recommendations based on soil nutrient analysis.
